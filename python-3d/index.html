🛺 Rickshaw Rush 3D

Python desktop driving prototype · real OpenStreetMap road geometry · OSRM route data · low-poly 3D auto-rickshaw

Get the game source

This is a Python/Ursina desktop game. Download the source and run it on Windows or another Python-compatible desktop. It cannot run as a native Ursina window inside this website.

Browse source on GitHubDownload repository ZIP

Run on Windows

  1. Install Python 3.10–3.12.
  2. Download the GitHub ZIP and extract it.
  3. Open PowerShell inside the python-3d folder.
  4. Run the commands below.
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py

Controls

  • W / ↑ — accelerate
  • S / ↓ / Space — brake
  • A / ← — steer left
  • D / → — steer right
  • Esc — quit

Map and routing

Downloads actual OpenStreetMap road geometry around Powai, Mumbai, and requests a road-following route from OSRM. Internet is needed. Public demo endpoints may rate-limit. © OpenStreetMap contributors.
